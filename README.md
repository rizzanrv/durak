# durak

Онлайн «Дурак»: Node.js + Socket.IO, серверная игровая логика, комнаты по
приглашению, боты и PWA-клиент.

## Запуск

```bash
npm install
cp .env.example .env      # JWT_SECRET обязателен для нормальной работы
npm start                 # http://localhost:3000
```

`PORT` по умолчанию 3000. Если `JWT_SECRET` не задан, сервер поднимет
случайный ключ на процесс и напишет предупреждение — все сессии умрут при
рестарте.

## Тесты

```bash
npm test        # node --test; для игровой логики зависимости не нужны
```

27 проверок: колода (24/36/52/72, козыри, сравнение карт), правила раунда
(атака, защита, «взял», перевод, окончание), скрытие чужих рук в состоянии,
выход игрока из комнаты, 30 полных партий AI против AI с проверкой, что карты
не теряются и не дублируются. CI: `.github/workflows/tests.yml`.

## Устройство

```
server.js          express + socket.io, комнаты, ходы, таймеры
game/deck.js       колода, canBeat / canAttack
game/Room.js       состояние партии: атака, защита, добор, перевод, конец игры
game/AI.js         бот, три уровня
routes/auth.js     регистрация, вход, сессии (bcrypt + jwt)
routes/friends.js  друзья и приглашения
db/init.js         sql.js (SQLite), схема
public/            клиент: index.html, обфусцированные js-бандлы, PWA
tests/             серверная логика
```

Правила держатся на сервере: клиент только отправляет намерение
(`attack` / `defend` / `take` / `transfer`), сервер проверяет его по состоянию
комнаты и рассылает новое состояние.

## Что важно знать

- Состояние партии отправляется каждому игроку отдельно (`Room.getStateFor`):
  своя рука целиком, у соперников — только `handCount`. Широковещательная
  рассылка `getState()` отдавала бы карты всех игроков любому, кто откроет
  DevTools.
- Первым атакует игрок с младшим козырем (сравнивается минимальный козырь в
  руке, а не первая найденная карта).
- Комнаты и таймеры живут в памяти процесса: рестарт завершает активные партии,
  второй инстанс за pm2 комнаты не увидит.
