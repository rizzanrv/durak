# 🃏 Durak Online - Современная карточная игра

Полнофункциональная онлайн версия классической русской карточной игры "Дурак" с красивым современным интерфейсом, режимом обучения и игрой с друзьями.

## ✨ Основные возможности

### 🎮 Игровые режимы
- **Классический** - стандартная игра 1 на 1
- **Переводной** - возможность переводить карты
- **Против ИИ** - 3 уровня сложности (Лёгкая, Средняя, Сложная)
- **Режим обучения** - игра с подсказками и объяснениями
- **С друзьями** - создание приватных игр
- **Кастомная игра** - полная настройка правил

### ⚙️ Настройки игры
- **Тип игры**: Подкидной или Переводной
- **Размер колоды**: 24, 36, 52 или 72 карты (две колоды)
- **Количество игроков**: от 2 до 6
- **Время на ход**: от 30 секунд до без ограничений
- **Сложность ИИ**: Лёгкая, Средняя, Сложная

### 👥 Социальные функции
- Система друзей
- Поиск игроков
- Приглашения в игру
- Онлайн статус
- Чат (в разработке)

### 🎨 Современный UI/UX
- **Темная тема** с градиентами и неоновым свечением
- **Glassmorphism** эффекты
- **3D карты** с реалистичными анимациями
- **Плавные переходы** и анимации

## 🎯 Игровая логика

### Подкидной дурак
1. Атакующий игрок кладёт карту
2. Защищающийся должен побить её старшей картой той же масти или козырем
3. Атакующий может подкинуть карты того же ранга
4. Если защищающийся отбил все карты - они уходят в биту
5. Если не смог отбить - берёт все карты со стола

### Переводной дурак
- Всё как в подкидном, но:
- Защищающийся может перевести первую атакующую карту
- Для перевода нужна карта того же ранга
- Следующий игрок становится защищающимся

### Окончание игры
- Игра заканчивается когда колода пуста
- Дураком становится тот, у кого остались карты
- Победителем - первый, кто избавился от всех карт

## 🤖 Искусственный интеллект

### Уровни сложности

**Лёгкая:**
- Часто берёт карты
- Играет случайными картами
- Не сохраняет козыри
- Идеально для новичков

**Средняя:**
- Разумные ходы
- Использует самые слабые карты для битья
- Старается не бить козырями
- Стандартная стратегия

**Сложная:**
- Анализирует ситуацию
- Оценивает стоит ли брать карты
- Сохраняет козыри
- Оптимизирует использование карт
- Продвинутая стратегия

### Режим обучения

В режиме обучения ИИ:
- Показывает свои мысли при ходе
- Объясняет почему выбрал ту или иную карту
- Предлагает лучшие ходы игроку
- Даёт советы по стратегии

Кнопка "Подсказка":
- Анализирует текущую ситуацию
- Предлагает оптимальный ход
- Объясняет обоснование

## 👥 Игра с друзьями

### Добавление друзей
1. Откройте вкладку "Друзья"
2. Введите имя игрока в поиск
3. Нажмите "Добавить"
4. Друг должен принять запрос

### Создание игры
1. В списке друзей нажмите 🎮 рядом с именем
2. Настройте параметры игры
3. Нажмите "Создать игру"
4. Друг получит приглашение
5. После принятия - оба игрока в лобби
6. Нажмите "Готов" и "Начать игру"

### Приглашение в существующую игру
1. Создайте комнату
2. В лобби нажмите "Пригласить друга"
3. Выберите друга из списка
4. Отправьте приглашение

## 🎨 Кастомизация

### Цветовая схема
Все цвета настраиваются через CSS переменные в `style.css`:

```css
:root {
  --accent: #7c5ce7;        /* Основной акцент */
  --green: #00d4aa;         /* Успех */
  --red: #ff6b6b;          /* Ошибка */
  --blue: #4facfe;         /* Информация */
  /* ... и другие */
}
```

### Локализация
Добавьте переводы в `public/i18n.json`:

```json
{
  "en": {
    "your_key": "English text"
  },
  "ru": {
    "your_key": "Русский текст"
  }
}
```
