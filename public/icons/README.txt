
Иконки сгенерированы как SVG файлы.

Для продакшн-версии рекомендуется конвертировать SVG в PNG:
- Используйте онлайн конвертер (например, cloudconvert.com)
- Или установите sharp: npm install sharp
- Или используйте Inkscape/GIMP для конвертации

Конвертируйте каждый icon-{size}.svg в icon-{size}.png
